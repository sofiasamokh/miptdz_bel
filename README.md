# 🎓 EvaEdu — образовательный портал о женском здоровье

Добро пожаловать в **EvaEdu** — это веб-сервис, созданный в рамках дипломного проекта, и являющийся частью экосистемы **EvaHealth**. Платформа ориентирована на просвещение в области женского здоровья и реализована с использованием **Django** и **Bootstrap 5**.

---

## 🚀 Возможности

- **📚 Словарь**  
  Подробные определения терминов, связанных с женским здоровьем.  
  ✔️ Проверка уникальности  
  ✔️ Поддержка изображений  
  ✔️ Статистика количества терминов

- **🧠 Обучающие карточки**  
  Быстрый доступ к ключевым понятиям и визуальному контенту.  
  ✔️ Возможность добавить вопрос для викторины прямо при создании карточки

- **🎯 Викторина**  
  Генерация вопросов на основе карточек  
  ✔️ Перемешивание вариантов  
  ✔️ Подсчёт баллов  
  ✔️ Только корректно заполненные карточки попадают в игру

- **ℹ️ О проекте + форма обратной связи**  
  ✔️ Имя  
  ✔️ Категория запроса  
  ✔️ Проверка текста (только кириллица, не менее 50 символов)  
  ✔️ Сохранение в `feedback.txt`

- **🔐 Админка**  
  ✔️ Просмотр, редактирование и удаление всех данных  
  ✔️ Регистрация суперпользователя

---

## 💻 Технологии

- Python 3.9
- Django 4.2
- SQLite (по умолчанию)
- Bootstrap 5
- HTML5, CSS3
- `pylint` (оценка кода, комментарии, валидации)
